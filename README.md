Live Preview: https://zainu04.github.io/night_wings_event_website/

As part of the Code Path Web Development Course, I built Night Wings, an event website for aviation enthusiasts who enjoy night photography of airplanes. The website lets users explore events, revisit memories, and easily interact with the community.

Key features include:

Hero Section - Engaging first impression with call to action buttons
RSVP – Quick and easy event registration
Dark Mode – A sleek, night-friendly interface
Animations – Smooth interactions that enhance the user experience
